StaticThings.StaticThings — Module
StaticThings

StaticThings provides tools to help write generic code that works with both static and non-static values and arrays.

StaticThings.maybestatic_reshape — Function
maybestatic_reshape(A, sz::SizeLike)

Reshapes array A to size sz.

If A is a static array and sz is static, the result is a static array. Other arrays are reshaped with the non-static size instead of being converted to an SArray. Like with reshape, the result shares the memory of a mutable A.

StaticThings.maybestatic_view — Function
maybestatic_view(A, r::Union{AbstractUnitRange,StaticUnitRangeLike})
maybestatic_view(A, from::IntegerLike, until::IntegerLike)

A view of the vector or tuple A over the index range r, resp. from index from to index until.

Static vectors of a bits type give static vectors for static indices, copies can't be told apart from views for them. Other static vectors give StaticArrays' view, which is statically sized for MArrays and SizedArrays. Tuples give tuples, other vectors a view.

StaticThings.size_from_type — Function
size_from_type(::Type{T})::StaticThings.SizeLike

Get the size (equivalent of StaticThings.maybestatic_size) of values of type T.

Requires values of type T to have a fixed known size, returns StaticThings.NoTypeSize{T}() otherwise.

For array types the size is determined via StaticArrayInterface.known_size.
