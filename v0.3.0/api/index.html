StaticThings.StaticThings — Module
StaticThings

StaticThings provides tools to help write generic code that works with both static and non-static values and arrays.

StaticThings.drop_leading_dims — Function
drop_leading_dims(A::AbstractArray, ::StaticInteger{N})

Drop the N leading dimensions of A, which must be of size one.

The axes of the remaining dimensions are kept. If they don't start at one, the array type has to support reshaping to such axes, as OffsetArray does and as dropdims requires too. Static arrays stay static.

StaticThings.maybestatic_view — Function
maybestatic_view(A, r::Union{AbstractUnitRange,StaticUnitRangeLike})
maybestatic_view(A, from::IntegerLike, until::IntegerLike)

A view of the array or tuple A along its first dimension, over the index range r, or from index from to index until.

Static arrays of a bits type give static arrays for static indices, because a copy of one can't be told apart from a view. Other static arrays give StaticArrays' view, which is statically sized for MArrays and SizedArrays. Tuples give tuples, other arrays a view.

StaticThings.sum_leading_dims — Function
sum_leading_dims(A, ::StaticInteger{N}; init)

Sum A over its N leading dimensions.

Returns an array over the remaining dimensions, a number if there are none, and A itself for N == 0. Static arrays stay static, and the remaining dimensions keep their axes. An init is passed on to sum.

Extended help

A lazy broadcast summed over all of its dimensions is reduced without materialization, if its style supports that. It then accumulates in index order instead of pairwise, like Base's reductions over selected dimensions do. Summing only some of its dimensions materializes it first, because Base has no reduction over selected dimensions of a Broadcasted. An empty broadcast is materialized too, unless an init provides the neutral element.

The sum is taken by the sum method of A's own type, so a change of representation can change the accumulator: sum of a static array of a narrow integer type accumulates in that type, sum of a plain array widens. An empty result takes its element type from Base, which may widen it.
